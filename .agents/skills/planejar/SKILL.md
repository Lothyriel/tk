# Planejar

Use `tk-linear` in **Plan a proposal** mode for the user's arguments.
If no proposal was supplied, ask what outcome they want to plan.
Investigate code and alternatives, prepare a card or useful parent/subtasks, and return the links and unresolved decisions. End at planning.

If skill activation by ID is unavailable, read [tk-linear](../tk-linear/SKILL.md).
