# Inventory grid font

`FiraMono-Medium.ttf` is the unmodified font bundled by Bevy Feathers
0.20.1 (`bevy_feathers/src/assets/fonts/` in the Cargo distribution).
Its copyright notice and SIL Open Font License 1.1 are in
[`FiraMono-LICENSE`](FiraMono-LICENSE).

SHA-256: `5f9173ce3d05fadef74c7eed06570d54e4f75bd0cd9860726fb2987a7f848292`.

Only inventory grid text uses this face. Bevy's default embedded Fira Mono
subset covers ASCII and remains unchanged elsewhere.
